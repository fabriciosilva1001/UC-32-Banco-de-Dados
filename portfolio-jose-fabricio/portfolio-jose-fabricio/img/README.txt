PORTFÓLIO — JOSÉ FABRÍCIO

Como abrir:
1. Extraia a pasta portfolio-jose-fabricio.
2. Abra o arquivo index.html no navegador.

Como adicionar uma foto:
1. Coloque sua imagem dentro desta pasta img.
2. No index.html, você pode inserir uma imagem usando, por exemplo:
   <img src="img/minha-foto.jpg" alt="Foto de José Fabrício">
3. Use um texto alternativo que descreva a imagem.

Sobre os projetos:
Os três cartões são sugestões acadêmicas e devem ser confirmados e ajustados para corresponder aos trabalhos realmente desenvolvidos. As prévias são ilustrações CSS, não capturas reais de projetos.

Sobre o formulário:
A validação funciona no navegador, mas nenhuma mensagem é enviada ou armazenada. Para envio real, é necessário configurar um backend ou serviço apropriado.
